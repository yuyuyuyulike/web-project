# web-project

个人网页小项目集合，全部是纯前端、可直接打开的单页项目。

## 项目

- **[奇点 · 网页黑洞](blackhole/)** —— WebGL2 实时史瓦西黑洞渲染器。
  线上：https://yuyuyuyulike.github.io/web-project/blackhole/

- **[侏罗纪求生 · 恐龙生存模拟器](dino-survival/)** —— Canvas 2D 程序化绘制的恐龙生存模拟器，
  零依赖零素材；支持手机触屏虚拟摇杆与键鼠。含元素吐息、人类部落、远古魔法、昼夜天气与生态 AI。
  线上：https://yuyuyuyulike.github.io/web-project/dino-survival/
