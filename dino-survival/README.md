# 侏罗纪求生 · 网页恐龙生存模拟器（魔幻纪元）

纯前端（零依赖、零构建、零素材文件）的恐龙生存模拟器，**同时支持手机触屏和电脑键鼠**。
所有图形都由 Canvas 2D 程序化绘制，所有音效都由 WebAudio 实时合成，整个游戏只有十几个文本文件。

线上：https://yuyuyuyulike.github.io/web-project/dino-survival/

## 快速开始

- **电脑**：直接双击 `index.html`（脚本用普通 `<script>` 加载，file:// 下也能跑）。
- **手机**：同一 WiFi 下在项目目录起个静态服务器，然后用手机浏览器打开：

```powershell
python -m http.server 8000      # 或 npx --yes serve -l 8000
```

用 http(s) 打开会注册 Service Worker，可"添加到主屏幕"离线全屏玩。

## 操作

| 动作 | 手机 | 电脑 |
| --- | --- | --- |
| 移动 | 左半屏任意位置按下拖动（浮动摇杆） | WASD / 方向键 |
| 撕咬（**自动瞄准**） | 右下红色「咬」 | J / Z / 空格 / 鼠标左键 |
| 元素吐息 | 紫橙色「焰/霜/雷/震」 | Q |
| 冲刺 | 「冲刺」 | Shift |
| 进食 / 饮水 / 祈祷 / 进洞 | 按住「进食」（进洞与祭坛是**点按**） | 按住 E / F |
| 咆哮 | 「吼」 | R |
| 巢穴（筑巢 / 迁巢 / 产蛋 / 睡觉） | 「巢」 | N |
| 暂停 | 右上 II | Esc |

**撕咬自动瞄准**：附近有目标时会自动转向最合适的那个（红色瞄准圈标出，360° 全向），
朝向只在咬的瞬间锁定 —— **走位完全由摇杆决定，不受攻击影响**。吐息也有轻度辅助瞄准。

设置里可切换摇杆左右手、画质、音效、震动、触屏按钮显隐、视野远近。

## 玩法

### 生存
- **五条状态**：生命 / 饱食 / 水分 / 耐力 / 魔力，另有成长条。饱食或水分归零就掉血。
- **食性**：肉食靠捕猎与啃尸，植食吃蕨类、灌木与地穴里的发光蘑菇（会随时间长回来）。
- **成长**：幼年 → 亚成年 → 成年 → 霸主。幼年期有伤害减免，开局还有 45 秒适应期。
- **昼夜天气**：完整昼夜（夜里只有身边一圈视野）、晴/多云/雨/雷暴/浓雾，雷暴真会落雷。
- **巢穴**：吃饱喝足可筑巢 → 产蛋 → 幼崽跟随作战；夜里在巢中睡觉可快进到天亮。
  **巢可以搬家**：走到新地点连按两次「迁巢」，巢和蛋一起搬过去。

### 元素吐息（消耗魔力）
| 物种 | 吐息 | 效果 |
| --- | --- | --- |
| 霸王龙 | 烈焰吐息 | 锥形高伤，点燃目标并在地面留下火焰 |
| 迅猛龙 | 雷霆吐息 | 直线穿透，连锁 2 个额外目标并短暂眩晕 |
| 三角龙 | 大地震荡 | 环形冲击，击退 + 眩晕全场敌人 |
| 副栉龙 | 霜冻吐息 | 锥形减速，还能扑灭身上与地面的火 |

站在**魔力水晶**或**符文圈**旁边回魔快 3~4.5 倍。

### 天上：翼龙
**无齿翼龙**在高空盘旋（有地面投影），会俯冲叼走小型猎物，甚至**偷你巢里的蛋**。
它在高空时近战打不到 —— 等它俯冲下来再咬，或者直接用吐息把它打下来。

### 地下：地穴地图
山脚下有 **3 个洞口**，站上去点「进洞」进入独立生成的地穴地图（洞道 + 洞厅）：
- 永夜、视野更小，靠**发光蘑菇 / 魔力水晶 / 岩浆 / 出口天光**照明；
- **岩浆**会点燃踩进去的生物（炽心遗物免疫）；
- 成群的**洞穴蝠龙**、夜行的**幽影龙**；
- 最深处的**远古祭坛**必掉一件遗物，由**熔岩暴龙**守着；
- 地下水潭可以喝水，蘑菇可以吃；回到中央出口点「出洞」返回地面（幼崽会跟着你上下）。

### 人类部落（第三方阵营）
3 座营地（帐篷、篝火、木桩、骸骨、**图腾柱**），成员有猎人（投长矛）、长矛战士、
萨满（火球 + 治疗族人）、酋长（精英）。他们对**所有恐龙**动手，会主动围猎野生恐龙。
咬碎图腾柱可让营地停止派兵并掉落遗物，同时惊动酋长。随机事件「部落狩猎队」会直扑你。

### 远古魔法
符文圈祈祷得 60 秒祝福（力量 / 迅捷 / 守护）；**8 种遗物**永久变异（最多 4 件）：
炽心、石肤、风鳞、再生鳞、龙魂、咒牙、霜心、灵脉。事件「魔潮」全场回魔 x3。

## 开发自测（无需浏览器）

`tools/` 用假 DOM/Canvas 在 Node 里跑**真实**的游戏与渲染代码，并自带软件光栅器把画面
转成 ASCII 轮廓 / PNG，用于没有浏览器时的视觉检查。

```powershell
node tools/uicheck.mjs    # JS 引用的 id/class/文件是否都存在
node tools/smoke.mjs      # 冒烟：四物种 x 22 秒 + 事件/天气/巢/睡眠/存档/死亡重开
node tools/probe.mjs      # 吃草、喝水、捕猎、啃尸、咆哮、生态自持、性能
node tools/probe2.mjs     # 卡位自救、四种吐息、部落/图腾/遗物、符文、幽影/龙王
node tools/probe3.mjs     # 自动瞄准、迁巢、翼龙飞行/偷蛋、地穴进出/岩浆/祭坛
node tools/inspect.mjs    # 恐龙 ASCII 轮廓 + 场景配色 + 屏内生物密度
node tools/inspect2.mjs   # 地形分布 / 岸边画面 / 夜幕光圈
node tools/inspect3.mjs   # 人类与图腾轮廓 + 吐息方向 + 营地画面
node tools/inspect4.mjs   # 翼龙/蝠龙俯视轮廓 + 地穴照明 + 瞄准圈
node tools/snap.mjs       # 输出 tools/shots/*.png 供肉眼查看
```

## 想调平衡改哪里

- 物种数值：`src/species.js`（速度/血量/伤害/食量/远程/吐息/飞行高度）。
- 吐息与遗物：`src/magic.js` 顶部的 `BREATHS` / `RELICS` / `BLESSINGS`。
- 自动瞄准范围：`src/game.js` `doAttack` 里的 `reach` 与 `pickAimTarget` 的弧度参数。
- 生态密度：`src/game.js` 的 `popTargets`（地表）与 `cavePop`（地穴）。
- 部落派兵：`src/magic.js` `updateVillages` 的 `want = 3 + min(4, day)`。
- 地穴形态：`src/world.js` `generateCave`（醉汉行走的步数/半径决定洞道疏密）。
- 昼夜长度：`src/game.js` 的 `dayLength`（默认 195 秒一天）。
