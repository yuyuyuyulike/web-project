# 奇点 · 网页黑洞

浏览器里的实时史瓦西（Schwarzschild）黑洞渲染器。纯前端、零依赖、单页面 —— 直接双击
`index.html` 即可运行（需要支持 WebGL2 的浏览器）。

画面里的每一个像素都是**沿弯曲时空积分光线**得到的，而不是贴图或后期特效。

---

## 快速开始

双击 `index.html`。或者起一个本地服务器：

```powershell
# 任选其一
python -m http.server 8080
npx serve .
```

## 它在算什么

单位制取史瓦西半径 `rs = 2M = 1`，于是 `M = 0.5`：

| 特征 | 半径 |
| --- | --- |
| 事件视界 | `r = 1` |
| 光子球 | `r = 1.5` |
| 最内稳定圆轨道 (ISCO) | `r = 3` |
| 临界撞击参数（黑洞阴影） | `b = 3√3/2 ≈ 2.598` |

**光线（零测地线）。** 从相机出发反向追踪光子。由轨道方程 `u'' + u = 3Mu²`（`u = 1/r`）
反解中心力，得到类笛卡尔坐标下的精确运动方程：

```
d²x/dλ² = -3 M h² x / r⁵ ,   h = |x × v| （运动常数）
```

因此弯曲量是**精确**的，不是“伪引力”近似。片元着色器用中点法（RK2）逐步积分，
步长随 `r` 自适应（越靠近视界越细）。光子落入 `r < 1` 即被吞噬（纯黑）；逃逸到远处
则用最终方向采样背景星空 —— 这就是爱因斯坦环与背景星场扭曲的来源。

**吸积盘。** 几何薄、光学薄的发射层。每当光线穿越赤道面就线性插值求交点，按斜程长度
`H / |cosθ|` 做光学薄辐射转移（`α = 1 - e^-τ`，前向累积并遮挡），所以同一条光线可以
先后击中盘的正面、背面以及绕行一圈后的次级像。

盘上叠加了：

- **开普勒较差转动** —— 采样坐标按 `Ω(r) ∝ r^(-3/2)` 反向旋转，内圈转得更快，自然产生剪切纹理
- **多普勒集束** —— `δ = 1/(γ(1 - β·n̂))`，亮度 `∝ δ³`，色温 `∝ δ`（靠近侧更亮更蓝）
- **引力红移** —— `√(1 - rs/r)`，同时作用于亮度与色温
- **黑体色温映射** —— `T ∝ r^(-0.72)` 经 CIE 1960 UCS 近似转 sRGB，而非手调渐变

**探针。** 「抛出探针」（或双击画面）投放测试粒子，按时间类测地线
`a = -(M/r³ + 3M h²/r⁵) x` 演化 —— 第二项正是近日点进动的来源。探针在着色器里按
「光线到线段的距离」发光，因此它同样会被引力透镜化，可能同时看到多个像。

**成像管线。** HDR 场景（RGBA16F）→ 时间累积 → 亮部提取 → 三级高斯泛光 →
ACES 色调映射 + 径向色散 + 暗角 + 颗粒。

| 输入 | 作用 |
| --- | --- |

## 值得一试

- **关闭「引力透镜」** —— 立刻退化成平直时空里的普通圆盘（预设「平直时空」）。对比之下
  才能看清透镜到底做了什么：盘的背面被抬到黑洞上方，形成那道拱形。
- **把「多普勒集束」拉到 0** —— 盘左右两侧的亮度差消失。真实黑洞不会这样。
- **倾角调到 0°** —— 完全侧视，可以看到盘穿过自身次级像。
- **预设「纯净透镜」** —— 关掉盘，只留被扭曲的星空与光子环。
- **「吞噬界面」** —— 让整个 UI 螺旋坠入奇点。右下角 `↺` 召回。

## 性能

默认开启**自适应画质**：帧率低于 26 时自动降低渲染倍率，高于 57 时回升（HUD 显示实际
分辨率）。若仍然吃力，手动调低「积分步数」（低 · 180）与「渲染倍率」。软件渲染
（SwiftShader）下大约 20 FPS，独立显卡上 1080p 满倍率通常可跑满 60 FPS。
